# Next.js + Node.js Monorepo

Author: Urmate

A two-app workspace with Next.js on the front and a dependency-light Node API in the backend.

## Stack

`Next.js`, `Node.js`, `TypeScript`

## Theme

- Name: Harbor Signal
- Primary: #0f766e
- Accent: #f59e0b
- Motion: 240ms soft rise, slow status sweep

Theme tokens are also stored in `.urmate/theme.json` for Urmate Builder.

## Commands

| Task | Command |
| --- | --- |
| install | `npm install` |
| dev | `npm run dev` |
| build | `npm run build` |
| preview | `http://localhost:3000` |

## Details

- Root workspaces
- Next.js frontend
- Node.js backend
- API proxy route
